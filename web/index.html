What is real, and what is not

  • AI modelYOLOv8n pretrained, runs on CPU through ONNX Runtime. Finds people and bags in every sampled frame.
  • TrackingOur own IoU tracker links detections into tracks with IDs.
  • RulesZone entry, loitering time, unattended object, rapid movement. Plain, deterministic logic, not deep learning.
  • MLIsolation Forest on this video's track features. It only switches on when there are enough tracks, otherwise the dashboard says it is inactive.
  • SeveritySum of named factor points. The explanation bars are the actual calculation.
  • UI onlyLayout, colours and animations. Every number you see comes from processing.
  • PrivacyEvidence frames blur people by default. Unblurring is a deliberate "authorized review" action.

Honest limitations

  • The system does not understand intent. It flags patterns (too long in a zone, object left alone, fast movement).
  • Small bags are hard for a tiny model at 320 px input, so object detection can miss them.
  • Anomaly scoring needs several tracks to be meaningful. On very short clips it stays off.
  • Thresholds are tuned by hand for the scene and are editable above the video.
